# dotfiles

My collection of dotfiles (configuration files).

![Screenshot of the Hyprland environment with Firefox on the left side and VSCode on the right](/assets/screenshot.png)

This configuration is setup as a bare git repository. You can learn more about it from this
[Atlassian article](https://www.atlassian.com/git/tutorials/dotfiles).

## Clone the repository

```sh
git clone --bare https://github.com/filintodelgado/dotfiles ~/.dotfiles
```
